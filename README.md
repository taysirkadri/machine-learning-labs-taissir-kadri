# Machine Learning practical sessions

This repository contains the practical work for the first three university machine-learning sessions.

## Structure

- [`ML-tp1/`](./ML-tp1/) - data exploration and preprocessing
- [`ML-tp2/`](./ML-tp2/) - PCA from scratch and with scikit-learn
- [`ML-tp3/`](./ML-tp3/) - regression hypothesis spaces and model generalization

Each session keeps its exercise PDF, solution notebook, and any small data or result files needed to run it.

The notebooks use beginner-level Python with pandas, NumPy, matplotlib, seaborn, and scikit-learn. The virtual environment and colleague example archives are kept outside the submitted repository history.
